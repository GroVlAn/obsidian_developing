**Семафор** — это примитив синхронизации, который ограничивает количество горутин (или потоков), одновременно получающих доступ к определённому ресурсу или участку кода.

В отличие от мьютекса (который пускает **только одну** горутину), семафор позволяет войти **N** горутинам одновременно (где N — заданное число разрешений или «пермитов»).

### Как это работает

- Семафор содержит счётчик разрешений.
- Когда горутина хочет войти в защищённую секцию, она вызывает **acquire** (захват):
    - Если счётчик > 0 → он уменьшается, горутина проходит.
    - Если счётчик = 0 → горутина блокируется и ждёт.
- Когда горутина выходит, она вызывает **release** (освобождение):
    - Счётчик увеличивается.
    - Одна из ожидающих горутин может быть разбужена.

### Когда использовать

1. **Ограничение числа одновременных подключений к БД**  
    Например, разрешить не более 10 одновременных запросов.
2. **Ограничение параллельных HTTP-запросов** к внешнему API, чтобы не превысить rate limit.
3. **Пул воркеров**  
    Запускаем не более K задач одновременно, остальные ждут.
4. **Ограничение расхода памяти/ресурсов**  
    Например, только 5 горутин могут одновременно обрабатывать большие файлы.
5. **Контроль параллелизма в операциях, где мьютекс избыточен**  
    Например, можно позволить 100 одновременных чтений, но только 5 записей.

Пример:

```go
package blocks 

import (
	"log"
	"sync"
	"time"
)  

type Semaphore struct {
	semaCh chan struct{}
}

func NewSemaphore(maxReq int) *Semaphore {
	return &Semaphore{
		semaCh: make(chan struct{}, maxReq),
	}
}

func (s *Semaphore) Acquire() {
	s.semaCh <- struct{}{}
}

func (s *Semaphore) Release() {
	<-s.semaCh
}

func SemaphoreExecute() {
	var wg sync.WaitGroup

	semaphore := NewSemaphore(2)  

	for i := 0; i < 10; i++ {
		wg.Add(1)
		go func(taskID int) {
			semaphore.Acquire() 

			defer wg.Done()
			defer semaphore.Release()

			log.Printf("Запущен рабочий %d", taskID)
			time.Sleep(1 * time.Second)
		}(i)
	}

	wg.Wait()
}
```
